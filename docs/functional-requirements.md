# Functional Requirements

This document lists the core functional requirements for the TODO app.

## Tasks

### Add a Task
- Users can create a new task by providing a title.
- A task may optionally include a due date at the time of creation.

### Delete a Task
- Users can permanently remove an existing task.

### Complete a Task
- Users can mark a task as complete.
- Completed tasks are visually distinguished from incomplete tasks.
- Users can unmark a completed task to restore it to an incomplete state.

### Edit a Task
- Users can edit the title of an existing task.
- Users can edit the due date of an existing task.

### Set a Due Date
- Users can assign a due date to a task when creating or editing it.
- The due date is displayed alongside the task.

### Sort Tasks
- Users can sort tasks by:
  - Due date (ascending or descending)
  - Completion status (incomplete first or completed first)
  - Creation date (newest or oldest first)
  - Title (alphabetical order)
